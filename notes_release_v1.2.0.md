## Eris Ezio's Launcher 1.2.0

### Nouveautés
- 🖥️ **Choix de l'écran** : range les fenêtres sur l'écran de ton choix (ou automatiquement sur le plus grand).
- 🎮 **DeSmuME** rejoint la liste : melonDS, DeSmuME, VisualBoyAdvance, mGBA et Azahar.

### Installation
1. Télécharge **ErisEzioLauncher1.2.0.exe** ci-dessous.
2. Télécharge [RunAsDate](https://www.nirsoft.net/utils/run_as_date.html) (gratuit, version 64 bits conseillée).
3. Lance le programme : il trouve tout seul tes émulateurs sur le bureau.

> Windows SmartScreen peut afficher un avertissement (programme non signé) :
> clique sur **Informations complémentaires** puis **Exécuter quand même**.

## Eris Ezio's Launcher 1.2.2

### Corrections
- 🐛 **Le launcher ne se ferme plus tout seul** quand il doit afficher une fenêtre « Ouvrir » : émulateur ou RunAsDate introuvable, ou bouton « … » des cartes ROM, GBA et Sauvegarde.
- 🛡️ **En cas d'erreur**, un message s'affiche au lieu d'une fermeture silencieuse, et le détail est enregistré dans `ErisEzioLauncher.log`, à côté du programme.

### Rappel des nouveautés de la 1.2
- 🖥️ Choix de l'écran où ranger les fenêtres.
- 🎮 Prise en charge de DeSmuME : melonDS, DeSmuME, VisualBoyAdvance, mGBA et Azahar.

### Installation
1. Télécharge **ErisEzioLauncher1.2.2.exe** ci-dessous.
2. Télécharge [RunAsDate](https://www.nirsoft.net/utils/run_as_date.html) (gratuit, version 64 bits conseillée).
3. Lance le programme : il trouve tout seul tes émulateurs sur le bureau, sinon il te demande où ils sont.

> Windows SmartScreen peut afficher un avertissement (programme non signé) :
> clique sur **Informations complémentaires** puis **Exécuter quand même**.

Un problème ? Ouvre un signalement dans l'onglet **Issues** en joignant le fichier `ErisEzioLauncher.log`.
