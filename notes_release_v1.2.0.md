## Eris Ezio's Launcher 1.2.0

### Nouveautés
- 🖥️ **Choix de l'écran** : range les fenêtres sur l'écran de ton choix (ou automatiquement sur le plus grand).
- 🎮 **DeSmuME** rejoint la liste : melonDS, DeSmuME, VisualBoyAdvance, mGBA et Azahar.

### Installation
1. Télécharge **ErisEzioLauncher1.2.0.exe** ci-dessous.
2. Télécharge [RunAsDate](https://www.nirsoft.net/utils/run_as_date.html) (gratuit, version 64 bits conseillée).
3. Lance le programme : il trouve tout seul tes émulateurs sur le bureau.

> Windows SmartScreen peut afficher un avertissement (programme non signé) :
> clique sur **Informations complémentaires** puis **Exécuter quand même**.
